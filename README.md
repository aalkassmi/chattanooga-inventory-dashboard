# Chattanooga Inventory Performance

Static page showing every Premier Truck Group of Chattanooga unit (new and used) with listing views, Google Ads share, leads, calls, price, days on lot and listing status.

- `index.html`: the page (no build step).
- `data/inventory.json`: the data. A refresh only replaces this file.

Sources: Mixpanel project 3822144 (dealer ID 955) for activity; Motive for live inventory and price.
